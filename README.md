# 🏝️ Campus Quest

> **「把現實的課業壓力，變成遊戲裡的成就感。」**

這是一款結合「大學課業管理」與「像素風角色養成」的互動式網頁遊戲。
在這裡，寫作業不再只是枯燥的待辦事項，而是賺取金幣、培養角色的破關過程。交出的每一份作業，都會變成像素小島上越來越熱鬧的可愛夥伴！

🔗 **遊戲連結 (Demo)**： [https://eloise26007.github.io/first-vibecoding-hw/] *(發布後請將此處替換為你的網址)*

---

## ✨ 核心宗旨

1. **打怪升級**：寫作業等於賺金幣、養角色，讓努力獲得具體的視覺回饋。
2. **溫柔陪伴**：沒有逾期扣分的懲罰機制，只有可愛的像素精靈陪你熬夜。
3. **看見努力**：現實中付出的汗水，直接餵養虛擬世界裡的小夥伴，與你的大學生活共同成長。

---

## 🎮 遊戲功能

* **📝 課業管理系統**
  * 支援新增、編輯、刪除作業，並可設定「科目」、「截止日期」與「難度」。
  * 具備「待完成」與「已完成」的篩選功能，逾期作業會有紅字溫馨提醒（但不扣分！）。
* **💰 任務獎勵機制**
  * 依照作業難度（簡單 / 中等 / 困難）給予不同的金幣與 EXP 獎勵。
* **🎓 角色養成**
  * 領取獎勵時，可選擇將 EXP 灌注給任一已解鎖的角色。
  * 每累積 50 EXP 即可升一級，見證角色的成長！
* **🛒 角色商店**
  * 使用努力賺來的金幣購買新角色，共有 15 隻隱藏精靈與神獸等你解鎖。
* **🎒 收藏與小島漫遊**
  * 已解鎖的夥伴會在首頁的「像素小島」上隨機跳躍與漫步，點擊還能查看當前等級。
  * 完整的 16 格角色收藏櫃，隨時檢視收集進度。
* **💾 本地自動存檔**
  * 遊戲進度自動儲存於瀏覽器 `localStorage`，重新整理也不怕資料不見。

## 🛠️ 技術架構

本專案採用最輕量、易維護的單一檔案架構：
* **HTML / CSS / JavaScript** (全部集中於 `index.html` 方便部署與修改)
* **無後端 / 無資料庫** (使用瀏覽器 `localStorage` 進行資料保存)
* **RWD 響應式設計** (完美支援電腦版與手機版介面)
